🔍 Security Tools

All tools use free public APIs — no key, no payment, just run it.

🔍

CVE Lookup

Search any CVE by ID — full detail card: description, CVSS score, affected vendors/products, and references.
Example: CVE-2021-44228 (Log4j)
🚨

CISA KEV Feed

Live feed of known exploited vulnerabilities from CISA, with exploitation status and reason.
Example: Linux KVM → Windows SMBv1
📦

Vulnerability Search

Find CVEs by vendor and product name. Search 'apache' + 'httpd' to see all related CVEs.
Example: vendor=apache product=httpd
🏷️

CPE Search

Search CVEs for a specific CPE (Common Platform Enumeration) product URI.
Example: cpe:2.3:*:apache:httpd
🌐

Shodan Host Scan

Free network host scan — open ports, services, organization, ASN, country. No key needed.
Example: 8.8.8.8 → ports 443,53
🔗

URLScan

Scan any domain and see all URLs, IPs, server headers, and MIME types found during the scan.
Example: github.com
📍

IPinfo Lookup

Free IP geolocation — country, city, ISP, ASN, timezone, coordinates for any IP address.
Example: 20.30.40.17
🛡️

DShield ISC

SANS Internet Storm Center threat feed for an IP address — check for reported attacks.
Example: 192.168.0.5
✉️

Email Reputation

Check email sender reputation and spam risk via EmailRep API.
Example: info@company.com
💾

Export Data

Download any result as JSON or CSV for offline analysis, reporting, and archive.
Example: CVE-2021-44228.json

🎯 Why SecView?

Designed for security professionals who want fast answers.

🧠 Built for Security Experts

Not another generic scanner. Designed around one workflow: ask a question, get a clean answer. No 20-step wizards, no noise.

🆓 100% Free, No Keys

Only free public APIs are used. No API keys to buy, no credit cards, no hidden costs.

🖥️ Two Interfaces, One Toolset

A rich terminal interface and a full-featured web UI. Choose your preferred way to work.

📋 Readable, Not JSON

Every tool returns clean, formatted text. CVE cards, severity badges, and tables — no raw JSON dumps anymore.

📐 Clean Architecture

One core library + two interfaces. Old, unused files are removed. The project is focused and maintainable.

🌐 Web-SaaS Ready

Flask-powered web app with a modern UI and fast load states. Ready to deploy anywhere.
